# 目录和生命周期

模块布局遵循管理器的标准。持久数据只写入 `/data/adb/novasched/`。Scene 协议仍要求 `/data/powercfg.json`、`/data/powercfg.sh` 和对应的 base 入口；它们是注册入口，首次原件集中保存到 `restore/scene/`。

迁移取得专用锁，检查旧控制、守护、监督与配置安装锁。任何旧锁正在使用时，不移动文件。安装可以完成，配置准备推迟到下次启动。无占用后迁移已知文件，冲突不覆盖；读取和停止流程兼容旧路径。

配置先验证再替换。原厂快照在写入节点前保存，只保留当前开机所需数据；首次 Scene 原入口用于卸载恢复。恢复失败时停止清理并保留数据。

动画分别处理取消、完成和超时。新转场开始前清理旧动画；减少动态效果和后台状态会释放动画。弹窗使用代次编号过滤过期回调，关闭完成后消费对应历史记录，交互锁按当前可见层级计算。

云更新只接受固定仓库和语义版本标签。官方校验文件通过 HTTPS 获取，镜像只传输 ZIP；校验完成后调用管理器安装命令，不自行绕过安装器解压到活动模块目录。
