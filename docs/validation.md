# v2.12.0 验证范围

作者 ZenJooo。基线为 v2.11.2，配置代际升为 392（仅 SM8650 内容重调，其余模板字节不变）。

## 本次修订的验证

- **Rust 回归：252 项全部通过**（WSL2 Ubuntu 宿主，原生 Linux /proc 环境执行，含进程身份活体回归）。在 234 项基线上新增/更新：FAS 基线中毒回拉（持续不足约 10 秒回拉、瞬态抖动不触发）、uclamp 所有权分离（boost=0 恢复基线/不降挡/基线空回 0）、输入脉冲按 FAS 值优先回落、损坏隔离文件只保留最新一份、gpu_devfreq 迁移"模板有才注入且保持关闭"、O3 十核 cpuset 集合比较迁移、SM8650 66% 小核上限解析。
- **宿主脚本校验全部通过**：WebUI 玻璃渲染 28 项、DOM/宿主场景（含新版本号断言）、玻璃性能预算、12 份模板双实现字节级一致（Python + Node，含 SM8650 gpu_devfreq 候选包）、48 组策略护栏（SM8650 候选包按停用断言）、安装器替身（管理器身份/失败中断/回执）、开机门控替身（有界等待、126/127 立即放弃、禁用取消、损坏退出、用户查询失败不刷屏）、WebUI 更新回滚、云更新校验回退。
- **构建与发布**：Windows 主机 NDK r27d 交叉编译 aarch64 release；ELF 为 AArch64 EXEC、无 INTERP/NEEDED、四个 LOAD 段 16 KiB 对齐；`package-release.py` 通过 CRC、版本一致性（module.prop / version.js / Cargo / npm / powercfg.json = 2.12.0 / 414）、执行权限、目录白名单、协议密钥与 ELF 逐字节一致性检查后出包。
- 本机无 Android 真机：功耗、帧时间、厂商温控交互、玄戒 O3 十核布局等仍需真机数据，清单见 v2.12.0-report.md。

这些检查覆盖已识别问题，不代表所有隐藏问题已清零，也不构成全部 ROM 和处理器的兼容承诺。
